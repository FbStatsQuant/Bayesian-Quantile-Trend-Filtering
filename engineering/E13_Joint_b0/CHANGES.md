# E-13a phase 2: changes to method/ (HQ GO 2026-11-25: fix the warm start and the z draw)

Every change is in BOTH samplers (`method/individual/Individual_Sampler_PMALA_Augmented.R`, `method/joint/Joint_Sampler_PMALA_Augmented.R`), with identical code. `e13b_zdraw_test.R` checks that the shared functions are identical.

**Why the stationary target is unchanged.**
- Changes 4–8 act only before the end of the burn-in (sweep ≤ `gibbs_burn`), and burn-in draws are discarded. MCMC validity does not depend on the starting state.
- After the burn-in, every kernel is the pre-E-13a code: P-MALA θ move, λ conjugate draw + ASIS, σ draw, δ adaptation.
- The one exception is Block 2 (the z draw), which now uses a different floating-point formula for the same law (changes 1–2).

| # | Where | Change | Why the target is unchanged |
|---|---|---|---|
| 1 | `rinvgauss` | The smaller root of the Michael–Schucany–Haas inverse-Gaussian draw is now computed as x = μ/(1 + w + √w·√(w+2)), with w = μy/(2λ), instead of μ + μ²y/(2λ) − (μ/2λ)√(4μλy + μ²y²). | The two roots of the MSH quadratic multiply to μ², so μ(1 + w − √(w²+2w)) = μ/(1 + w + √(w²+2w)) exactly: **the same law, the same random numbers, the same accept/flip rule**. Only the rounding differs. The old form cancels catastrophically when w is large (tiny residuals). Evidence: `e13b_zdraw_test.R` (KS test against the exact law). |
| 2 | `draw_z` | The floor on \|e\| goes from 1e-10 to 1e-100. The clamps z ∈ [1e-8, 1e4] are unchanged. | The floor only acts when \|e\| < 1e-10. Below it, the exact law is the \|e\| → 0 limit to double precision (χ = e²/(t2σ) < 1e-20). The old floor at 1e-10 could only be used because the old formula failed below it anyway. |
| 3 | `prox_admm_metric.cpp` | `admm_core` gets an optional flag that reports whether the residual-based exit fired (default `nullptr`: every existing caller is bitwise unchanged). A new export, `prox_admm_metric_conv`, returns the prox plus that flag. It is used only by the warm start. | No exact kernel calls it. `pmala_move`, `prox_admm_metric` and the box kernel compute exactly what they did before. |
| 4 | `pilot_fit`, init `"data"` (new default; joint: replaces the offsets init) | The start is now data-only. A running median s of y (window ≈ n/20). θ0_j = s + the τ_j-quantile of y − s, ordered in j by construction. σ0_j = the mean check loss of θ0_j (the ALD maximum-likelihood scale given θ0_j). z0 ~ z \| θ0, σ0 (an exact conditional draw). λ0 = m as before. The old starts (individual `"y"`/`"tf"`) remain available. | It is the initial state only. It uses no truth and no RNG beyond the z0 draw. |
| 5 | `warm_prox` (warm sweeps, it ≤ `warm` = 200) | The warm conditional MAP (the same optimisation problem as before) is solved by ADMM to a relative residual tolerance of 1e-6 and, for the joint sampler, accepted only inside the box. Otherwise the interior-point solver of `prox_box_metric.cpp` (IPM only, tolerance 1e-8) is used. Each fallback is logged (`warm_fallback`). The individual script now also compiles `joint/prox_box_metric.cpp` for this. | It acts in warm sweeps only (warm ≤ burn), which are discarded. |
| 6 | λ hold (`warm_lambda = "hold"`) | λ stays at λ0 = m during the 200 warm sweeps; the conjugate λ draw and the ASIS move start at sweep 201 (as before for ASIS). | Burn-in only. (Reason: a conditional MAP is sparse in Dθ, so the conjugate draw λ ~ Gamma(m + 1, b0 + ‖Dθ_MAP‖₁) pushes λ up, the next MAP is sparser, and λ runs to the ceiling (m + 1)/b0. With accurate warm solves this happens in every chain: `e13b_warm_check.R` "draw", λ 1e7 at b0 = 1e-5, acceptance 0, MSE 0.18 (individual) and 0.24–0.91 (joint). The old inaccurate solver hid this in the individual sampler and triggered it in the joint one.) An option `lambda_hold_extra` (hold for more exact sweeps) exists; 200 was tried and did nothing, so the default is 0. |
| 7 | σ guard (`sigma_guard = 10`) | During the burn-in, if a σ draw exceeds 10 × σ0_j it is reset to σ0_j and logged (`sigma_guard`). | It acts in burn-in only. It is off after the burn-in, so post-burn σ draws are the exact conditional. |
| 8 | Logs | The fit returns `warm_fallback`, `warm_ipm_unconverged` (the IPM stopped on its stall rule; this is its normal end state and still accurate to about 1e-10 per tests P4/P6, so it is informative only), `sigma_guard`, `sigma0` and `lambda_hold_until`. | No effect on the chain. |
| 9 | Joint test T1 | It compares J = 1 with the individual sampler under init `"data"` (it was `"y"`). | Test only: bitwise identity is still required. |
| 10 | Counters (added for E-14) | `gibbs_pmala_aug` also returns `n_ipm_fallback` (the number of warm sweeps where the IPM replaced ADMM) and `n_sigma_guard` (the number of σ-guard firings). `gibbs_joint_pmala` returns the same, one value per level. | Return values only; no effect on the chain. |

Switches back to the pre-E-13a burn-in pieces: `theta_init = "y"` (individual only), `warm_lambda = "draw"`, `sigma_guard = Inf`. The joint offsets start and the old warm solver (fixed 300 ADMM iterations, accepted whatever their accuracy) were replaced, not kept as options.
