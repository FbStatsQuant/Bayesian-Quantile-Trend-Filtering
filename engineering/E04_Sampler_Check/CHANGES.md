# E-04 changes (one line each: file, what, why)

None of these touches the paper's sampler (`method/individual/*`) or any result reported in the paper.

- `engineering/E02_Rate_Sims/analyze.R`: the slope bootstrap now resamples replicate IDs jointly across n (paired). Why: replicate s reuses data seed s at every n (shared noise prefix), so independent per-n resampling misstates the slope CIs. Point estimates are unchanged.
- `engineering/E02_Rate_Sims/e02_lib.R`: the samplers also return pointwise 2.5/97.5% bands and posterior SDs. Why: needed for the E-04 agreement table. No change to any draw.
- DONE (E-03 commit 0707c8b), `method/individual/Individual_Sampler_PMALA_Augmented.R`: reset the settings block from `order <- 1L` to `order <- 2L` (and b0/asis/adapt_target/iterations to the production config). Why: the paper uses k = 2. The frozen packages that produced the paper's results (`Simulations/Individual/NOTS/inner_individual/source/`, `config.R`: order 2L, b0 0.01, asis TRUE, target 0.50) used order 2L; only the standalone pilot defaults differ. No reported result changes, because the production runs passed explicit arguments.
- `engineering/E02_Rate_Sims/e02_lib.R`: new clamp-free exact latent draws (`draw_z_exact`, with the zero-residual limit z = 2qσχ²₁; `draw_iw_exact`, with λ²s ~ χ²₁ at v = 0), now the default (`exact_latents = TRUE`) for all runs launched from now on (HQ's final call, 2026-11-22: exact at no cost). All E-02 runs completed or launched before this change, including kink25, lamlong and lamxl (code_v15), used the production clamps (z ∈ [1e-8, 1e4], |e| ≥ 1e-10, 1/s ≤ 1e6·λ²). Why: Astra findings 1–2; the paired test B2 shows the clamps' effect on E-02 quantities is ≤ 2% (rough spread −1 to −1.8%), so those runs stand.
- `engineering/E02_Rate_Sims/e02_lib.R`: the ESS of the thinned midpoint series is reported as `ess_mid_thinned`, no longer multiplied by the thinning interval. Why: Astra finding 6 (mis-scaled diagnostic). The headline ESS (of Δ², on the unthinned trace) was always correct.
- `engineering/E02_Rate_Sims/e02_lib.R`: clamp-hit counters `clamp_rate_z` and `clamp_rate_iw`. Why: diagnostics for findings 1–2.
- Paper sampler (`method/individual/*`): no change. Its z safeguard is documented in the paper (appendix, safeguard (i)), and B2 shows it is immaterial.
- `engineering/E04_Sampler_Check/e04_A3.R` (new): independent high-penalty reference (HQ item 4). No change to any sampler.
